# 비트 분석 방식별 정확도 리포트

GLOWSYNC Editor(EfxCreator)의 "곡 분석 설정"에서 고를 수 있는 비트 분석 방식을, Light-Stick-Music의
Beat Accuracy Checker 기록으로 비교한 결과입니다.

- 비교 대상: 43곡
- 기준(GT) 엔진: Beat Transformer, madmom, librosa (허용 오차 ±70 ms)
- 지표: F-measure (F). 1.0에 가까울수록 앱의 비트가 GT와 일치합니다
- 기록 날짜: V3 자동 = 2026-10-14 (Shape of You만 2026-11-16), V1 = 2026-07-07, 템포 고정 = 2026-11-17

---

## 1. 요약

| 항목 | 결과 |
|---|---|
| 템포 고정으로 바꾼 곡 | 9곡 |
| 43곡 전체 평균 F 변화 (Beat Transformer·madmom 평균) | 0.863 → **0.896 (+0.033)** |
| 바뀐 9곡만의 평균 F (madmom) | 0.805 → **0.961** |
| F 0.7 미만 곡 (madmom) | 3곡 → **0곡** |
| F 0.9 이상 곡 (madmom) | 34곡 → **38곡** |
| V1 엔진 | 눈에 띄게 나은 곡 없음 → debug 빌드에서만 노출 |

결론: 엔진을 바꾸지 않고, **곡마다 사용자가 "템포 고정"을 선택**하는 구조만으로 평균 +0.033을 얻었습니다.

---

## 2. 분석 방식

| 방식 | 하는 일 | 적합한 곡 |
|---|---|---|
| 템포 자동 추정 (기본, V3) | BPM은 분석기가 정하고 비트는 소리를 따라 찾음 | 대부분의 곡 |
| 지정 BPM으로 추적 | BPM을 직접 입력하고 비트는 소리를 따라 찾음 | 자동이 BPM을 반/두 배로 잘못 잡은 곡 |
| 템포 고정 | 입력 BPM 근처에서 정확히 맞추고 비트를 일정한 격자로 고정 | 템포가 일정한데 비트 위치가 어긋난 곡 |
| 전체 주기 기반 추정 (V1) | 곡 전체의 반복 주기로 BPM과 비트를 정함 (debug 전용) | - |

## 4. V1(전체 주기 기반 추정) 비교

Light-Stick-Music의 BeatDetectorV1과 EfxCreator의 V3(현재 기본)를 같은 곡 41곡으로 비교했습니다.

| GT 엔진 | V1 평균 F | V3 평균 F | V1이 나은 곡 | V3가 나은 곡 |
|---|---|---|---|---|
| Beat Transformer | 0.765 | 0.809 | 3 | 14 |
| madmom | 0.882 | 0.929 | 2 | 11 |
| librosa | 0.760 | 0.769 | 4 | 10 |

- 곡별(Beat Transformer·madmom 평균)로 V1이 5%p 넘게 나은 곡은 **1곡**(Pimple, +0.14), V3가 나은 곡은 9곡, 나머지 31곡은 차이가 5%p 이내였습니다.
- Pimple도 템포 고정(0.94~0.99) 앞에서는 V1(0.57~0.62)이 크게 뒤집니다.
- V1은 **느린 곡에서 BPM을 정확히 두 배로 잡습니다**: 진미령 - 미운사랑(69.8 → 139.5), TOMBOY(74.1 → 146.3), 장윤정 - 초혼(72.3 → 142.9).
  V1의 120 BPM 중심 사전확률 때문으로 보입니다.
- 주의: V1 기록은 7월, V3 기록은 10월이라 엔진만 다른 비교는 아닙니다.
- 결정: V1은 debug 빌드에서만 노출하고 release에서는 숨깁니다.

## 5. 추가 개선 후보 시뮬레이션

템포 고정을 적용하지 않은 나머지 곡에 같은 방식을 적용했을 때의 예측입니다
(입력 BPM은 각 곡의 분석 BPM, 기준은 Beat Transformer·madmom 평균).

- 개선 11곡 / 비슷 19곡 / 악화 8곡
- 개선 후보는 이후 실제로 적용해 위 3절의 5곡(Dynamite, Soda Pop, Tick-Tack, 사랑을 했다, 천년지기)이 확인되었고, 아직 적용하지 않은 후보는
  I'll Like You, TOMBOY, 모든 날 모든 순간, 금잔디 - 오라버니, 02_Magnetic_ILLIT, Almond Chocolate입니다 (예측 +0.03~0.05).

## 6. 개별 사례

### aespa - Next Level
- V3 자동 0.736 / 0.788 / 0.816, V1 0.738 / 0.787 / 0.801, 템포 고정(계산) 0.61 / 0.80 / 0.82
- V1은 V3 자동과 사실상 같은 비트를 잡았고, 템포 고정은 오히려 약간 나빠집니다.
- 맞는 구간은 이미 100%이고 120~160초 구간만 낮은데, 고정으로는 해결되지 않습니다.
  정답 비트의 간격도 510~720 ms로 편차가 큽니다. 청감상 문제가 없다면 그대로 두는 곡입니다.

### 장윤정 - 사랑 참 (템포가 바뀌는 곡)
구간별 템포(BPM):

| | 0~90초 | 90~210초 |
|---|---|---|
| madmom | 72 | 143 |
| Beat Transformer | 72 | 72 |
| librosa | 144 | 144 |
| V3 자동 | 143~146 | 143 |
| 템포 고정 (72.3) | 72 | 72 |

- 앞부분은 고정(F 0.99~1.00)이, 뒷부분은 자동(F 0.97~1.00)이 맞습니다. 현재 방식으로는 곡 전체에 한 가지 템포만 적용할 수 있습니다.
- 90초에서 두 결과를 이어 붙이면 madmom 기준 F가 자동 0.829, 고정 0.727에서 **0.936**으로 오릅니다 (librosa 0.861, Beat Transformer는 곡 끝까지 72로 보아 0.579).
- 해결하려면 "구간별 BPM"(변경 시점과 앞뒤 BPM 입력) 기능이 필요합니다. 아직 구현하지 않았습니다.

## 7. 4번째 방식 "템포 고정 + 구간 보정" 시뮬레이션

격자 간격은 곡 전체에서 고정하고, 위상만 앞뒤 8박 안에서 따라가게 한 방식입니다.

| 방식 | 43곡 평균 F (Beat Transformer·madmom) |
|---|---|
| V3 자동 | 0.891 |
| 템포 고정 | 0.874 |
| 구간 보정 | 0.882 |

(Pimple, The Drum, 초혼, 사랑 참은 이미 고정된 기록이 기준이라 "자동" 열이 실제보다 높게 나옵니다.)

- Next Level, Supernova에서는 고정으로 떨어진 점수를 자동 수준으로 되돌렸습니다.
- Bach, Good Goodbye, Golden은 고정보다는 덜 나쁘지만 자동에는 못 미칩니다.
- 자동보다 확실히 좋아지는 곡이 새로 생기지 않아 **추가하지 않기로** 했습니다.
  대신 "템포 고정" 설명에 "곡 전체에서 비트가 계속 어긋날 때 쓰고, 일부 구간만 틀리거나 템포가 변하는 곡에는 맞지 않는다"를 분명히 적는 쪽을 권합니다.

## 8. 결론과 후속 과제

1. 비트 분석 엔진은 V3를 기본으로 유지하고, 곡마다 "템포 고정"을 선택하는 현재 구조가 효과적입니다 (평균 +0.033, 바뀐 9곡 madmom 기준 +0.16).
2. V1은 debug 비교용으로만 남깁니다.
3. 4번째 방식(구간 보정)은 추가하지 않습니다.
4. "템포 고정" 설명 문구 보강: 전 구간에서 비트가 어긋난 곡에 가장 효과적이고, 템포가 변하는 곡에는 맞지 않음.
5. 장윤정 - 사랑 참처럼 템포가 바뀌는 곡을 위한 "구간별 BPM" 기능은 비슷한 곡이 더 있는지 확인한 뒤 결정.
6. 템포 고정 후보로 남은 곡(I'll Like You, TOMBOY, 모든 날 모든 순간, 금잔디 - 오라버니, 02_Magnetic_ILLIT, Almond Chocolate)은 필요하면 직접 적용해 확인.
